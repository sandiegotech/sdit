# Day 02 — The First Program Was Written by Hand

Ten minutes on the page. One table from 1843, your first three lines, and the first entry in a log you will keep all semester.

Read the table as a program. Operation 1 multiplies two numbers. Operation 2 does something with the result. Down the rows, the columns fill with what the machine would hold at each step, and in the middle of the table the sequence loops back on itself to run again. Lovelace traced every value by hand, because there was nothing else to trace it with.

---

## One idea

A program exists before it runs. It is written by a person who has to see the whole thing in their head, and Note G is the proof: the first published program ran for 170 years on paper before anyone built a machine that could execute it, and when they did, it worked, except for one wrong sign in a row near the end. The first program had the first bug.

That is the discipline this course grades, and the catalog name for it is programming fundamentals. Not typing. Seeing what the machine will do before it does it, line by line, and knowing what you meant well enough to notice when the result differs.

Today you write your first program, and you do it the way 2026 does it: with the assistant open. Ask it for three lines of Python that print something about today's date. Run them. Then read every line and say to yourself what each one does, in words, before you trust it. If you cannot say it, you do not have a program yet; you have a result.

Then open a plain text file, name it the verification log, and write entry one: what you asked for, what came back, and whether it was what you meant. That log is where this course lives. By Day 15 it is the record of a person learning to direct a machine and check it, which is the only kind of programming left.

## If you're still curious

Three doors. Open one, or none — they'll be here tomorrow too.

**Read the real thing.** [Lovelace's Notes on the Analytical Engine](https://www.fourmilab.ch/babbage/sketch.html), 1843, in full and free. Scroll to Note G and read the last two pages, where she says the Engine "has no pretensions whatever to originate anything." People are still arguing with that sentence.

**Watch the machine get built.** [Ben Eater, "Making logic gates from transistors"](https://www.youtube.com/watch?v=sTu3LwpF6XI). Fourteen minutes. This is a preview of CS 120, where you build upward from exactly this to a computer that runs a program you wrote.

**Ask someone.** Ask an older relative: *"What was the first machine you ever had to give instructions to?"* Listen for the moment it did exactly what they said instead of what they meant. Everyone has that story, and it is always Day 1 of this course.
